# Licence

**Status: NOT YET AGREED. All rights reserved until this file is updated.**

The COMP0016 launch lecture (Task 4) asks every team to create a `licence.md` *after speaking to the supervisor to confirm* the licence. The partner is Avanade, so ownership of the code and the licence choice must be agreed with:

- the academic supervisor / client liaison, and
- the Avanade project contact (in writing, by email; see [project-management/agreements/](project-management/agreements/)).

Options to discuss (decide and record in [docs/06-governance/ip-licensing.md](docs/06-governance/ip-licensing.md)):

| Option | Typical use |
|---|---|
| MIT | Permissive open source, if Avanade agrees to public release |
| Apache-2.0 | Permissive, with an explicit patent grant |
| Proprietary / partner-owned | Partner keeps the IP, repo stays private |

Third-party components keep their own licences. In particular, **TabPFN model weights are licensed separately from the TabPFN code** (see [research/wiki/providers/prior-labs.md](research/wiki/providers/prior-labs.md)), and each dataset has its own terms (see [data/README.md](data/README.md)).

When agreed, replace this file with the full licence text and record the decision date and the agreement email reference here.
