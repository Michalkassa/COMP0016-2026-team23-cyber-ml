# Agentic Meta-Statistician

Can an AI assistant improve a modeller's analysis without adding errors?

| Step | Output |
|---|---|
| 1. Roles | Planner, data checker, experimenter, statistical reviewer, explainer |
| 2. Tools | Data profiling, leakage checks, run approved experiments |
| 3. Human approval | Every change approved and logged |
| 4. Evaluate | Assistant vs plain-script workflow, scored with an agreed rubric |

Uses the anomaly-detection task as its test case.
