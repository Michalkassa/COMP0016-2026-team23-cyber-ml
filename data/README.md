# Data

**Raw data is never committed.** `data/raw/` and `data/processed/` are git-ignored. This folder holds datacards (provenance, labels, licence, limitations) and access instructions only.

| Dataset | Datacard | Access | Status for this project |
|---|---|---|---|
| Wendover web-server logs (sanitised; 2026-09-06 → 2026-10-07; fail2ban labels) | [DATACARD-wendover.md](DATACARD-wendover.md) | `./scripts/fetch_data.sh` → `data/raw/wendover/` | Candidate. **Usage permission to be confirmed with the client** |
| CIC-IDS2017, UNSW-NB15, EMBER (public benchmarks) | see [research/wiki/data/](../research/wiki/data/) | Official sites (see wiki) | Candidates |

Note: the Wendover datacard mentions `raw_sanitized/` text logs. These are **not** in the upstream repo. Only the three CSVs are.

## Layout

```text
data/
├── README.md, DATACARD-*.md   committed
├── raw/<dataset>/             git-ignored, exactly as obtained, never edited
└── processed/                 git-ignored, regenerated by code from raw/
```

When adding a dataset, write a datacard (owner, collection period, schema, labels, licence/terms, privacy, biases, leakage risks, version/hash) and record it in [docs/06-governance/ethics-gdpr.md](../docs/06-governance/ethics-gdpr.md).
