# Templates

Copy a template to its destination (see the table in [CONTRIBUTING.md](../CONTRIBUTING.md#where-things-go)) and fill it in. Module Task 3 asks for professional templates for **video submissions, reports, weekly minutes and work packages**, agreed with the client. Record that agreement in `project-management/agreements/`.

| Template | Used for | Frequency |
|---|---|---|
| [weekly-progress.md](weekly-progress.md) | TA in-lab progress check | Weekly |
| [meeting-minutes.md](meeting-minutes.md) | Client, supervisor/TA, team meetings | Each meeting |
| [sprint.md](sprint.md) | Sprint plan + review | Fortnightly |
| [work-package.md](work-package.md) | A unit of work for one person | Fortnightly |
| [agreement-record.md](agreement-record.md) | Written (email) agreement with client | As needed |
| [build-notes.md](build-notes.md) | Demo build release notes | Fortnightly |
| [video-plan.md](video-plan.md) | Monthly progress video: script + submission record | Monthly |
| [blog-post.md](blog-post.md) | Development blog | Fortnightly |
| [report.md](report.md) | Formal report (term notes, technical report, client report) | Per term / as needed |
| [decision-record.md](decision-record.md) | Comparing 3+ options and recording a decision | Each significant decision |
| [experiment-record.md](experiment-record.md) | One experiment / benchmark run | Each experiment |
